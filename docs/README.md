## Rules for Contributors & AI Agents

- Do not redefine product requirements in code. Changes go through the PRD process.
- Keep responsibilities clear (see Architecture Principles in the SAD).
- Prefer the simplest solution that works reliably.
- Update IMPLEMENTATION.md and TASK.md after completing work.
